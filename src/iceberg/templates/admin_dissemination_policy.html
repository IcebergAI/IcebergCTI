Rule shape

when selects the products a rule speaks about (omit it for all of them); audience selects stakeholders. LIMIT_TO keeps only that audience; EXCLUDE withholds from it.

    "id": "exec-only",

    "effect": "LIMIT_TO",
    "when": {"intel_level": ["STRATEGIC"]},
    "audience": {"audience_group_ids": [1]}
  }
